# 依敏老師的貼文範例（風格參考）

以下摘自她在粉專「女性身心靈平衡的優雅實踐」已發布、自己很滿意的貼文。
學的是**結構、比喻方式和語氣**，不要整段照抄。

---

## 範例一：何謂血脂與尿酸～（文字貼文）

```
何謂血脂與尿酸～

🚚 血脂：血管裡的貨車和回收車

比喻：

壞膽固醇 LDL 像「送垃圾的貨車」，
會把油脂堆到血管壁上，越堆越多就塞住。

好膽固醇 HDL 像「回收車」，把血管裡的油脂載走。
所以好膽固醇是越高越好，太低才是紅字。

三酸甘油酯像血液裡的「油」，
吃太多甜的、澱粉、喝酒都會讓它升高。

代表：血管「堆垃圾」的風險變高。

不代表：總膽固醇高就一定很危險。
　　要看是「貨車太多」還是「回收車很多」。
而且壞膽固醇的目標值因人而異，
　　有糖尿病、心臟病的人要控制得更低，
　　所以「落在正常範圍」也不一定代表對你來說夠好。

💎 尿酸：身體的廢物鹽

比喻：尿酸像溶在水裡的鹽，太多溶不下就會變成小小的「結晶」，
　　像碎玻璃卡在關節裡，就是痛風。
```

**值得學的地方**
- 一個主角配一組比喻，而且比喻之間有關聯（貨車／回收車／油）。
- 「不代表」裡同時破除迷思（總膽固醇高≠一定危險）和提醒例外（慢性病的人目標更低）。
- 「好膽固醇越高越好，太低才是紅字」——把反直覺的地方直接講白。

## 範例二：何謂血壓與血糖？（文字＋圖卡）

文字片段：
```
糖化血色素＝過去約 3 個月的平均甜度（像看一段影片）

代表：身體處理糖的能力變差了。
　　100～125 的「糖尿病前期」是最好的黃金逆轉期。

不代表：一次偏高就確定是糖尿病，
　　通常要再驗一次或搭配糖化血色素確認。
另外，空腹沒滿 8 小時、前一晚大吃也會影響結果。
```

圖卡結構：
- 主標題：何謂血壓與血糖？　右上簽名「～依敏」
- 副標題：看懂數字背後的意義，才是真正的健康管理
- 左上小字：早知道 早預防 更健康！
- 左區（藍）：血壓｜水管裡的水壓 → 比喻、代表、不代表（一次高不等於高血壓、緊張趕路喝咖啡沒睡好、白袍高血壓）→「要在家多天、多次量，才看得準」
- 右區（粉）：血糖｜血液裡的糖水太甜 → 兩個指標（空腹血糖＝拍一張照片；糖化血色素＝看一段影片）→ 代表、不代表
- 中間：穿綠色手術服、戴聽診器的護理師插圖
- 底部橫幅：重視血壓與血糖，就是守護心臟、血管與未來！
- 三個行動：定期量測（家中多天多次才準確）｜調整生活（飲食、運動、睡眠）｜從現在開始（小改變，大不同）
- 右下簽名：健康的路上你並不孤單 ～依敏

**值得學的地方**
- 「照片 vs. 影片」的比喻，一秒就分清空腹血糖和糖化血色素。
- 「黃金逆轉期」：給讀者希望，而不是恐懼。
- 「不代表」提醒了測量誤差（空腹不足、前一晚大吃、白袍效應），這是護理師才會想到的實用細節。

## 範例三：何謂「代謝症候群」？（週一｜看懂數字，和依敏一起定稿）

```
何謂「代謝症候群」？～

📝 身體的「健檢成績單」

5 科及格線，來對一下答案：
① 腰圍：女 < 80、男 < 90 公分
② 血壓：< 130／85
③ 空腹血糖：< 100
④ 三酸甘油酯：< 150
⑤ 好膽固醇：女 ≥ 50、男 ≥ 40
　（這科是越高分越好！）

3 科沒過，就是代謝症候群。

🍩 腰圍常是最先亮紅字的那科
肚子的油會包住內臟，像穿了一圈游泳圈。
可惜這圈不能救命😅
只會拉著血壓、血糖、血脂一起退步。

代表：糖尿病、心臟病、中風的風險變高了。

不代表：被當掉了！
👉 這張成績單可以補考，
　　而且沒有補考次數限制～
瘦瘦的人也先別急著交卷，
一樣可能有科目沒過喔！

📏 今晚的隨堂小考：
拿軟尺沿著肚臍繞一圈，
吐完氣再看數字。
偷吸肚子不算喔😆

早知道、早預防、更健康！～依敏

#女性身心靈平衡的優雅實踐 #麻醉專科護理師
#代謝症候群 #腰圍 #三高 #內臟脂肪 #健檢報告
```

**值得學的地方（這篇是依敏確認過「最像她」的版本）**
- 長度：約 350 字，手機滑 1～2 次。原本較長的版本被她要求精簡過。
- 幽默順著比喻延伸：成績單 → 對答案、補考沒有次數限制、別急著交卷、隨堂小考。
- 說中大家心照不宣的小動作：「偷吸肚子不算喔😆」。
- 「不代表」只留最重要的兩點：不是被當掉（給希望）＋瘦的人也可能（破迷思）。
- 結尾只留留言＋私訊各一句，留言問題一兩個字就能回答。
- 依敏挑比喻的過程：集點卡、監視器、儀表板、烏雲、成績單，她選了「健檢成績單」，因為最生活化、人人秒懂。
