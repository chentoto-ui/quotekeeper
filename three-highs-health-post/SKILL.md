# 三高健康管理貼文（一三五固定發文）

## 這個 Skill 在做什麼
幫依敏老師寫「看懂數字、不再害怕紅字」的三高衛教貼文。
讀者是一般民眾（尤其是中年女性與她們的家人），他們拿到健檢報告會緊張、看不懂、也不知道下一步。
依敏的價值是：**25 年麻醉護理的專業 ＋ 用生活比喻講清楚 ＋ 溫暖不嚇人**。
貼文要讓人看完覺得「原來是這樣！我可以做到」，而不是被數字嚇到。

## 依敏的聲音：好朋友的專業提醒
這是整個 Skill 最重要的一段，寫每一句之前都想著它。
依敏不是在台上上課的老師，而是**剛好很懂醫學的好朋友**：
跟你喝咖啡時，笑著提醒你「欸，那個數字要注意一下喔」。
她要讀者感受到的是被關心，不是被要求、被糾正。

**幽默是她的招牌**，用法是：
- **讓比喻延伸出笑點**：選定一個比喻後，順著它玩下去。
  例：成績單 → 「可以補考，而且沒有補考次數限制」「隨堂小考」「先別急著交卷」；
  游泳圈 → 「可惜這圈不能救命😅」
- **說中大家心照不宣的小動作**：例如「量腰圍時偷吸肚子不算喔😆」「健檢前一週突然很養生」。
  讀者會心一笑，就會覺得「她懂我」。
- **笑點落在情境上，不落在讀者身上**：不嘲笑胖、不嘲笑生病，也不用讓人難堪的梗。
- 一篇 2～4 個小笑點就夠，最重要的還是把數字講清楚。

寫完自問：**如果好朋友這樣跟我說，我會覺得被關心，還是有壓力？**

## 寫作流程

### 1. 先確認主題（不清楚就先問）
如果她只說「幫我寫週一的貼文」，先看 `references/topic-bank.md` 推薦 2～3 個主題讓她挑。
如果她給了主題，直接確認三件事（可以一次問完）：
- 這篇是週幾？（決定用哪種貼文類型，見下表）
- 有沒有想加的真實小故事或臨床觀察？（有真實經驗的貼文最動人）
- 需不需要附「圖卡文字」？

| 發文日 | 類型 | 重點 |
|---|---|---|
| 週一 | 📖 看懂數字 | 「何謂○○」：比喻＋代表＋不代表＋標準值 |
| 週三 | 🥗 生活實踐 | 吃、動、睡、量測的具體小步驟 |
| 週五 | 💡 迷思破解／Q&A | 一個常見誤會，或一個讀者常問的問題 |

這個節奏依敏已經確認過。若某週她想調換，以她當下的決定為主。

### 2. 用招牌架構寫內文
依敏最有辨識度的寫法如下（範例見 `references/examples.md`，寫之前先讀）：

```
標題（例：何謂血脂與尿酸～）

[emoji] 主角名稱：一句話比喻（例：🚚 血脂：血管裡的貨車和回收車）

比喻：
用生活中的東西說明它是什麼、怎麼運作。

代表：
這個數字高（或低）代表身體發生了什麼事。

不代表：
大家常見的誤會、不用過度恐慌的情況、要注意的例外。
```

**為什麼是這個架構**：「代表」讓人知道要重視，「不代表」讓人放下不必要的恐慌——這正是護理師在臨床最常做的事，也是她跟一般健康帳號不一樣的地方。

寫作要點：
- **比喻只用一層、一個畫面**：讀者要能一秒想像出來。依敏退回過「鑰匙＋生鏽門鎖」，因為要同時記住鑰匙、門鎖、生鏽三樣東西，太繞；她選了「冰箱塞爆了」、「健檢成績單」、「脂肪搬家」這種家裡、生活裡天天看得到的畫面。寫之前不確定選哪個時，可以先給她 3～5 個比喻選。
- **比喻要具體、有畫面**：水管與水壓、糖水、貨車與回收車、溶不掉的鹽。同一篇裡的比喻要能互相呼應。
- **一次只講 1～2 個主角**，講透比講多重要。
- **精簡最重要**：依敏擔心讀者沒耐心，全文（不含 hashtag）控制在約 350 字、手機大約滑 1～2 次的長度。
  - 直接進主題，不要「前面我們聊過……」這類暖場
  - 「不代表」挑最重要的 1～2 點，意思重複的就合併
  - 結尾呼籲只留「留言＋私訊」各一句，分享邀請可省略
  - 「已在服藥先問醫師」只在談飲食、運動、藥物時才加
  - 寫完先自己刪一輪：拿掉這句，讀者會看不懂嗎？不會就刪
- **句子短、分段多**，手機一滑就能讀。一行盡量不超過 20 字。
- **不要替她編造個人經驗**：自嘲或生活小故事很加分，但要用她提供的真實經驗。她沒提供時，可以在交稿後問她「有沒有相關的小故事想加？」，不要自己編。
  同樣地，不要寫「很多姊妹跟我說」「病人常問我」這種像是她親身聽到的句子，改用「常聽到有人說」。
- **數字用台灣的標準**，並標明是「一般成人」參考值（見 `references/health-facts.md`）。
- **語氣**：像熟識的護理師朋友在聊天，親切、略帶幽默、真誠。可以用「～」結尾，emoji 只放在段落標題，不要每句都放。

### 語氣紅線：不要業配感、不要說教感
依敏特別在意這兩點。讀者一覺得「在賣東西」或「在被教訓」，就會直接滑走。

**避免說教**：讀者不是學生，是一起變健康的朋友。
- 少用命令句：「你應該」「一定要」「必須」「不可以」「千萬別」
- 改用陪伴句：「我們可以試試」「我自己也是……」「先從一個小改變開始就好」
- 先同理再建議：承認改變很難（「我知道下班後還要運動真的很累」），再給一個做得到的小步驟
- 適度自嘲或幽默：分享自己也愛吃甜、也會偷懶的真實時刻
- 建議一次只給 1～2 個，不要列一長串「該做清單」

**避免業配感**：
- 不提任何產品、品牌、「我自己都在吃的○○」
- 不用促銷語氣：「錯過可惜」「趕快」「限時」「改變人生」
- 不用誇大保證：「三週就降下來」「一定有效」

| ❌ 說教／業配 | ✅ 依敏的說法 |
|---|---|
| 你一定要每天量血壓！ | 這週試試在家量 3 天就好，你可能會發現跟在醫院量的不一樣喔～ |
| 想改善血糖，私訊我了解好物 | 健檢報告的紅字看不懂嗎？歡迎私訊我，我們一起把它看懂 |
| 不可以再喝手搖飲了！ | 我也超愛手搖飲😂 先從全糖改半糖，身體會感謝你的 |

### 3. 結尾
- 給一個「今天就能做」的小行動（例：這週在家量 3 天血壓，早晚各一次）。
- **固定簽名**（貼文最後、hashtag 之前；圖卡右下角也用同一個，品牌印象一致）：
  ```
  預防勝於治療
  預防醫學｜營養醫學 ～依敏
  ```
  簽名前可以加一句溫暖的話，例如「健康的路上，你並不孤單💛」，每篇換個說法。
  （舊範例裡的「早知道、早預防、更健康！～依敏」是以前的簽名，已不再使用。）
- **互動呼籲（每篇都要有，依敏很重視）**：同時邀請「留言」和「私訊」，語氣是好奇、陪伴，不是招攬。
  - 留言：問一個容易回答的小問題，讓人只要打一兩個字就能參與。
    例：「你的健檢報告，哪一項最常出現紅字？留言告訴我～」「你是『照片派』（只驗空腹血糖）還是『影片派』（有驗糖化血色素）？」
  - 私訊：邀請分享困擾或提問，強調「一起看懂」，不暗示會推薦產品。
    例：「如果報告上的數字讓你有點擔心，歡迎私訊我，我們一起把它看懂 💛」
  - 可再加一句分享：「身邊有人剛拿到健檢報告嗎？分享給他看看～」
  - 每篇換一下說法，不要每次都一模一樣。
- **Hashtag**：放在全文最後。
  - 固定兩個，每篇都要有：`#女性身心靈平衡的優雅實踐` `#麻醉專科護理師`
  - 再從**這篇內文的關鍵字**挑 3～5 個，例如這篇談血脂與尿酸，就用 `#血脂` `#壞膽固醇` `#好膽固醇` `#尿酸` `#痛風`。讀者搜尋這些字時才找得到她。
  - 關鍵字要真的出現在內文裡，不要放跟內容無關的熱門標籤。

### 4. 安全檢查（交稿前一定要過）
詳見 `references/compliance.md`，最重要的三點：
- **不推銷、不提任何產品或保健食品品牌**（包含 USANA）。這是衛教貼文，信任感是她最大的資產；一旦像業配，讀者會連專業內容一起懷疑，也可能踩到台灣食品廣告法規。
- **不做個人診斷、不建議停藥或改藥**，要提醒「已在服藥的人，調整請先和醫師討論」。
- **不嚇人**：不用「死亡」「可怕」「千萬」這類恐嚇字眼。

### 5. 交稿格式
````
【週○｜貼文類型】主題

（可直接複製的貼文全文，放在 code block 裡方便複製）

---
📝 圖卡文字（如果她需要）
- 主標題：
- 副標題：（例：看懂數字背後的意義，才是真正的健康管理）
- 左／右區塊：比喻、代表、不代表的濃縮短句（每點 ≤ 15 字）
- 底部標語：（例：重視血壓與血糖，就是守護心臟、血管與未來！）
- 三個行動小圖示：定期量測／調整生活／從現在開始
- 右下簽名：預防勝於治療｜預防醫學｜營養醫學 ～依敏
- 👩‍⚕️ Q版依敏：位置＋動作＋表情＋對話框（每張圖卡都要有，見下方說明）

✅ 安全檢查：已確認無業配感、無說教感、無個人診斷、數字為一般成人參考值、結尾有留言＋私訊呼籲
````
最後問她一句：「語氣、長度、比喻有沒有想調整的地方？」

## 圖卡上的 Q 版依敏（每張圖卡都要有）
依敏有自己的 Q 版人物，原圖在 `assets/yimin-chibi.jpg`。
她是讀者在圖卡上認得出「這是依敏的貼文」的招牌，所以每張圖卡都要安排她出場，
而且要跟主題、比喻互動，不要只是站在旁邊當裝飾。

**人物特徵**（請 AI 生圖或在 Canva 找素材時照這個描述，保持每張一致）：
- 日系 Q 版插畫風，粗黑線條、柔和平塗、米白底色
- 棕色頭髮、低馬尾，大大的棕色眼睛，溫柔微笑
- 深藍色手術帽，上面有可愛的貓咪臉和小圓點
- 深綠色刷手服（V 領），脖子掛黑色聽診器

**圖卡文字裡要寫出**：
- **位置**：例如右下角、中間、主標題旁
- **動作**：要跟比喻有關。例如成績單篇拿紅筆打分數、冰箱篇用力推冰箱門、搬家篇幫脂肪搬箱子
- **表情**：微笑、眨眼、驚訝、偷笑……配合貼文的幽默感
- **對話框**（可選，≤ 12 字）：例如「可以補考喔！」「冰箱該整理囉～」

**生圖提醒**：用 AI 生圖時，把 `assets/yimin-chibi.jpg` 當參考圖上傳，人物才不會每張長得不一樣。
在 Canva 也可以先把這張圖去背，存成固定素材，每張圖卡直接拖進來換動作。
