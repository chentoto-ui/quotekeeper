# 三高健康管理貼文（一三五固定發文）

## 這個 Skill 在做什麼
幫依敏老師寫「看懂數字、不再害怕紅字」的三高衛教貼文。
讀者是一般民眾（尤其是中年女性與她們的家人），他們拿到健檢報告會緊張、看不懂、也不知道下一步。
依敏的價值是：**25 年麻醉護理的專業 ＋ 用生活比喻講清楚 ＋ 溫暖不嚇人**。
貼文要讓人看完覺得「原來是這樣！我可以做到」，而不是被數字嚇到。

## 寫作流程

### 1. 先確認主題（不清楚就先問）
如果她只說「幫我寫週一的貼文」，先看 `references/topic-bank.md` 推薦 2～3 個主題讓她挑。
如果她給了主題，直接確認三件事（可以一次問完）：
- 這篇是週幾？（決定用哪種貼文類型，見下表）
- 有沒有想加的真實小故事或臨床觀察？（有真實經驗的貼文最動人）
- 需不需要附「圖卡文字」？

| 發文日 | 類型 | 重點 |
|---|---|---|
| 週一 | 📖 看懂數字 | 「何謂○○」：比喻＋代表＋不代表＋標準值 |
| 週三 | 🥗 生活實踐 | 吃、動、睡、量測的具體小步驟 |
| 週五 | 💡 迷思破解／Q&A | 一個常見誤會，或一個讀者常問的問題 |

這是建議的節奏，她若想換也完全可以，以她的決定為主。

### 2. 用招牌架構寫內文
依敏最有辨識度的寫法如下（範例見 `references/examples.md`，寫之前先讀）：

```
標題（例：何謂血脂與尿酸～）

[emoji] 主角名稱：一句話比喻（例：🚚 血脂：血管裡的貨車和回收車）

比喻：
用生活中的東西說明它是什麼、怎麼運作。

代表：
這個數字高（或低）代表身體發生了什麼事。

不代表：
大家常見的誤會、不用過度恐慌的情況、要注意的例外。
```

**為什麼是這個架構**：「代表」讓人知道要重視，「不代表」讓人放下不必要的恐慌——這正是護理師在臨床最常做的事，也是她跟一般健康帳號不一樣的地方。

寫作要點：
- **比喻要具體、有畫面**：水管與水壓、糖水、貨車與回收車、溶不掉的鹽。同一篇裡的比喻要能互相呼應。
- **一次只講 1～2 個主角**，講透比講多重要。
- **句子短、分段多**，手機一滑就能讀。一行盡量不超過 20 字。
- **數字用台灣的標準**，並標明是「一般成人」參考值（見 `references/health-facts.md`）。
- **語氣**：像熟識的護理師朋友在聊天，親切、略帶幽默、真誠。可以用「～」結尾，emoji 只放在段落標題，不要每句都放。

### 3. 結尾
- 給一個「今天就能做」的小行動（例：這週在家量 3 天血壓，早晚各一次）。
- 溫暖收尾，可用她的招牌句：「健康的路上，你並不孤單 ～依敏」或「早知道、早預防、更健康！」（兩者擇一，不要每篇都一樣）。
- 一句互動邀請（例：你的健檢報告哪一項最常出現紅字？留言告訴我～）。
- 3～6 個 hashtag，固定包含 `#女性身心靈平衡的優雅實踐` `#依敏護理師`，再加主題相關的。

### 4. 安全檢查（交稿前一定要過）
詳見 `references/compliance.md`，最重要的三點：
- **不推銷、不提任何產品或保健食品品牌**（包含 USANA）。這是衛教貼文，信任感是她最大的資產；一旦像業配，讀者會連專業內容一起懷疑，也可能踩到台灣食品廣告法規。
- **不做個人診斷、不建議停藥或改藥**，要提醒「已在服藥的人，調整請先和醫師討論」。
- **不嚇人**：不用「死亡」「可怕」「千萬」這類恐嚇字眼。

### 5. 交稿格式
````
【週○｜貼文類型】主題

（可直接複製的貼文全文，放在 code block 裡方便複製）

---
📝 圖卡文字（如果她需要）
- 主標題：
- 副標題：（例：看懂數字背後的意義，才是真正的健康管理）
- 左／右區塊：比喻、代表、不代表的濃縮短句（每點 ≤ 15 字）
- 底部標語：（例：重視血壓與血糖，就是守護心臟、血管與未來！）
- 三個行動小圖示：定期量測／調整生活／從現在開始

✅ 安全檢查：已確認無產品推銷、無個人診斷、數字為一般成人參考值
````
最後問她一句：「語氣、長度、比喻有沒有想調整的地方？」
